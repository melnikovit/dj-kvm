# dj-kvm: Панель управления виртуализацией QEMU/KVM и Libvirt

**dj-kvm** — это веб-платформа для централизованного управления, шаблонизации, мониторинга и администрирования гипервизоров **QEMU/KVM** на физических (bare-metal) серверах через протокол **Libvirt**.

---

## Назначение проекта

Проект разработан для инженеров инфраструктуры и системных администраторов, эксплуатирующих серверы KVM:
- Предоставить единый интерфейс управления парком KVM-гипервизоров без необходимости установки тяжеловесных монолитных решений.
- Обеспечить надежное и безопасное взаимодействие с сокетом Libvirt без необходимости сборки с CGO и использования небезопасных удаленных TCP-сокетов `libvirtd`.
- Автоматизировать подготовку, шаблонизацию и быстрое развертывание виртуальных машин с начальной настройкой через Cloud-Init.
- Предоставить удобный доступ к последовательным текстовым консолям (`virsh console`) и графическим экранам (VNC/SPICE) прямо из веб-браузера.
- Организовать непрерывный сбор телеметрии и мониторинг состояния физических хостов и гостевых доменов.

---

## Архитектура и стек сервисов

Стек `docker-compose.yml` включает в себя:
1. **`core`** (`melnikovit/dj-kvm:latest`) — Ядро управления (Go backend + React SPA frontend).
2. **`db`** (`postgres:16-alpine`) — База данных гипервизоров, шаблонов, пользователей, аудита и ключей.
3. **`prometheus`** (`prom/prometheus:v2.54.1`) — Сбор метрик с хостов и агентов с динамическим discovery (`promsd`).
4. **`grafana`** (`grafana/grafana:11.2.0`) — Преднастроенные дашборды мониторинга KVM хостов и виртуальных машин.

### Порты сервисов по умолчанию

| Сервис | Порт | Переменная в `.env` | Описание |
| :--- | :--- | :--- | :--- |
| **dj-kvm Web UI & API** | `8089` | `DJKVM_PORT` | Главный веб-интерфейс и API ядра |
| **Grafana** | `3001` | `GRAFANA_PORT` | Дашборды мониторинга KVM хостов и доменов |
| **Prometheus** | `9091` | `PROMETHEUS_PORT` | Prometheus TSDB и сбор телеметрии |

## Быстрый старт

### 1. Клонирование и настройка окружения

```bash
# Скопируйте файл переменных окружения
cp .env.example .env

# Отредактируйте .env, задав надежные пароли и секретные ключи:
# - POSTGRES_PASSWORD
# - ADMIN_PASSWORD
# - JWT_SECRET
# - DJKVM_SECRETS_KEY
# - GRAFANA_ADMIN_PASSWORD
nano .env
```

### 2. Запуск сервисов

```bash
docker compose up -d
```

### 3. Доступ к интерфейсу

- **Веб-панель dj-kvm**: `http://localhost:8089` (Логин: `admin`, Пароль: из `.env`)
- **Grafana**: `http://localhost:3001` (Логин: `admin`, Пароль: из `.env`)
- **Prometheus**: `http://localhost:9091`

## Ключевые функциональные возможности

### 1. Управление жизненным циклом виртуальных машин (Domains)
- **Операции питания**: Создание, запуск, корректное выключение по ACPI, принудительный останов (force stop/destroy), перезагрузка, приостановка и возобновление (pause/resume), автозапуск при загрузке хоста (autostart).
- **Конфигурация оборудования**: Гибкая настройка виртуальных ядер vCPU (topology, sockets, cores, threads), оперативной памяти, эмуляции чипсетов (Q35, i440FX), BIOS/UEFI (OVMF) и типов виртуализации.
- **Привязка устройств**: Подключение дисков VirtIO SCSI/VirtIO Block, сетевых адаптеров VirtIO, PCI Passthrough и USB устройств.

### 2. Шаблоны и генерация Cloud-Init
- **Библиотека шаблонов**: Каталог готовых базовых образов операционных систем (Ubuntu, Debian, AlmaLinux, Rocky Linux, Alpine, CentOS).
- **Автоматизация Cloud-Init**: Автоматическая генерация `NoCloud` ISO-образов и передача параметров конфигурации: сетевые настройки (статический IP, DHCP, gateway, DNS, маршруты), пароли пользователей, SSH-ключи авторизации, пакеты для автоматической установки и custom runcmd скрипты.
- **Мгновенный Provisioning**: Развертывание полностью готовой и сконфигурированной виртуальной машины за несколько секунд.

### 3. Пулы хранения и управление дисками (Storage Pools & Volumes)
- **Поддержка типов пулов**: Управление пулами хранения различных форматов — каталоги файловой системы (`dir`), LVM volume groups (`logical`), ZFS пулы, iSCSI и сетевые хранилища NFS.
- **Операции с томами (Volumes)**: Создание, изменение размера (resize), клонирование, сжатие и конвертация дисковых образов (QCOW2, RAW).
- **Sparse-аллокация**: Контроль тонкого выделения дискового пространства и отслеживание фрагментации.

### 4. Виртуальные сети (Virtual Networks)
- **Управление сетевыми топологиями**: Настройка сетей в режимах NAT, Routed, Isolated и прямого моста (Bridged Network через системный `br0` / `vmbr0`).
- **Контроль IP-пространства**: Управление встроенным сервером DHCP/DNS (dnsmasq в составе Libvirt), статическая привязка IP по MAC-адресам, просмотр активных арендованных адресов.

### 5. Снимки состояния (Snapshots) и резервные копии
- **Древовидная структура снимков**: Создание снимков состояния дисков и оперативной памяти виртуальных машин.
- **Откат к точкам сохранения**: Мгновенный откат состояния гостевой ОС к выбранному снимку в дереве зависимостей.
- **Экспорт и импорт бэкапов**: Создание полных архивных копий виртуальных машин для переноса или холодного восстановления.

### 6. Интерактивные консоли управления
- **Последовательная консоль (Serial Console)**: Прямой доступ к текстовой консоли виртуальной машины через `virsh console` в браузере (позволяет администрировать систему даже при сбое сетевых интерфейсов или отсутствии графической подсистемы).
- **Графический доступ VNC / SPICE**: Встроенный высокоскоростной веб-клиент для удаленного управления графическим рабочим столом виртуальных машин с поддержкой передачи клавиатурных сочетаний.

### 7. Сводный обзор пула гипервизоров (Fleet Management)
- **Агрегированная аналитика**: Единый дашборд состояния всех физических серверов KVM, суммарная загрузка процессоров, свободной оперативной памяти и дискового пространства пулов.
- **Топологическая карта**: Наглядный граф распределения виртуальных машин по гипервизорам, сетям и хранилищам.
