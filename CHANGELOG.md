# Журнал изменений (Changelog) - dj-kvm

Все значимые изменения в панели управления виртуализацией **dj-kvm** (QEMU, KVM & Libvirt).

Формат журнала основан на принципах [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

---

### [dj-kvm] Версия 7e446163 (2026-08-15 00:51:57 UTC)
- **Событие**: Сборка и публикация в Docker Hub (`melnikovit/dj-kvm`)
- **Изменения**: Релиз 7e446163: fix: deploy core without restarting prometheus on busy :9090

### [0.1.0] - 2026-08-14
#### Добавлено
- **Мониторинг**: Полноценный стек мониторинга на базе Prometheus (v2.54.1) и Grafana (v11.2.0) в `docker-compose.yml`.
- **Дашборды**: Предустановленные дашборды `overview.json` (гипервизоры KVM, виртуальные машины, vCPU, RAM, дисковый пул) и `hosts.json` с автопровижинингом.
- **Dynamic Discovery**: Интеграция `file_sd` (`prometheus/file_sd/agents.json`, `node.json`, `cadvisor.json`) и правила алертов `rules/basic.yml`.
- **CI/CD**: Downstream-триггер для автоматической публикации публичных образов в Docker Hub (`melnikovit/dj-kvm`) и синхронизации документации в GitHub (`melnikovit/dj-kvm`).

### [0.1.0] - 2026-08-12 (Roadmap Releases A–C)
#### Добавлено
- **Графическая консоль noVNC**:
  - Встроенный браузерный WebSocket VNC-прокси для прямого взаимодействия с графическим интерфейсом виртуальных машин без установки сторонних клиентов.
- **Мастер создания ВМ (Create VM Wizard)**:
  - Пошаговый визард создания виртуальных машин с выбором шаблонов ОС (Ubuntu, Debian, AlmaLinux, Rocky, Alpine, Windows).
  - Автоматическая генерация Cloud-Init конфигураций (`user-data`, `meta-data`, `network-config`) и сборка загрузочного ISO-образа на лету.
- **Снимки состояния и Клонирование**:
  - Управление деревом снимков состояния ВМ (QCOW2 internal/external snapshots) с возможностью быстрого отката.
  - Полное и связанное (linked) клонирование виртуальных машин.
  - Горячее изменение конфигурации (CPU/RAM Hotplug) без остановки гостевой ОС.
- **Резервное копирование дисков**:
  - Агентский движок резервного копирования виртуальных дисков по расписанию.
  - Мгновенное восстановление ВМ из архивов резервных копий.
- **Живая миграция (Live Migration)**:
  - Перемещение работающих виртуальных машин между KVM-гипервизорами без прерывания обслуживания.
- **Enterprise функции**:
  - Мультитенантность (изолированные рабочие пространства и проекты).
  - Интеграция с OIDC SSO провайдерами.
  - Централизованный журнал аудита операций.
  - Полная спецификация API в стандарте OpenAPI 3.0 (`docs/openapi.yaml`).

### [0.1.0] - 2026-08-12
#### Добавлено
- **Консоли и Терминалы**:
  - Интерактивный Serial PTY терминал через WebSocket (xterm.js) к последовательному порту гостевых ОС.
- **Управление ресурсами гипервизора**:
  - Пулы хранения: создание, запуск, остановка и удаление пулов (Directory, LVM, NFS, iSCSI, Ceph/RBD).
  - Виртуальные тома: создание дисков QCOW2/RAW, изменение размера, удаление, клонирование.
  - Виртуальные сети: управление виртуальными коммутаторами Libvirt (NAT, Routed, Isolated Bridge).
- **Файловый менеджер**:
  - Проводник по файловой системе хоста и гостевых систем через агентский RPC `guestfs`.
- **Карта топологии**:
  - Интерактивное визуальное отображение KVM-хостов, распределения виртуальных машин, сетей и пулов хранения.

### [0.1.0] - 2026-08-10
#### Добавлено
- Первоначальный импорт и запуск платформы **dj-kvm**:
  - Прямой RPC-клиент Libvirt на чистом Go (`go-libvirt`) без необходимости компиляции системных библиотек CGo (`libvirt-dev`).
  - Полное управление жизненным циклом ВМ (Start, Shutdown, Force Off, Pause, Resume, Reset, Destroy).
  - Легковесный WSS агент `dj-kvm-agent` для установки на bare-metal KVM гипервизоры.
  - Автоматическое определение версий агента (`scripts/ci/resolve-agent-version.sh`).
  - Конвейер сборки образов в GitLab CI и SSH-деплой.
